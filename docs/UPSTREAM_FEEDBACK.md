# Upstream feedback log

This file is intentionally empty at project start.

The objective is to record **implementation-derived** feedback for the Agent Baseline maintainers. A useful entry must contain:

- control ID and exact ambiguity/gap observed;
- environment and implementation context;
- reproducible evidence;
- operational impact;
- a proposed wording or testability improvement, if appropriate.

Do not open upstream issues simply to advertise this repository. The contribution is valuable only if the implementation reveals a real problem.
