# Agent Baseline Evidence Lab v0.9.0

v0.9.0 turns the project from a single-run evidence lab into a customer-ready before/after governance validation workflow.

## Highlights

- **Golden Customer Flow** — one fail-closed lifecycle for readiness, signed baseline verification, agent execution, assessment, response evidence, attestation signing, assurance, customer packaging and final handoff signing.
- **Privacy-minimized evidence** — project and home filesystem prefixes are removed before evidence persistence, including the hash-chained trace ledger.
- **Portable customer evidence packs** — customer handoffs are self-contained, private-key-free and offline-verifiable.
- **Governance Delta** — compares two verified assessment runs control by control without inventing a security or trust score.
- **Evidence-aware transition semantics** — distinguishes control improvement/regression from evidence gain/loss, evaluator recovery/error, scope change and unchanged controls.
- **Signed governance delta** — the before/after statement is recomputable from the source bundles and can be authenticated with the same Ed25519 verification key.
- **Offline comparison handoff** — one signed ZIP contains both customer evidence packs, the governance delta JSON/HTML, its signature and the public verification key.
- **Adversarial verifier regression matrix** — keeps the distinction between internal consistency, external anchoring and source completeness explicit.

GitHub also provides the standard source-code archives for the release tag.

## Install from the downloaded wheel

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install ./agent_baseline_evidence_lab-0.9.0-py3-none-any.whl
abl --help
```

## Verify downloads

On Linux:

```bash
sha256sum -c SHA256SUMS
```

On macOS:

```bash
shasum -a 256 -c SHA256SUMS
```

The release manifest additionally binds the package artifacts to the exact GitHub Actions source commit.

## Manager-facing paths

Single-run lifecycle:

```bash
make golden-demo
```

Before/after customer handoff:

```bash
make comparison-pack \
  BEFORE=evidence/abl-<before> \
  AFTER=evidence/abl-<after>

make comparison-pack-verify
```

## Claims boundary

This remains a community project. It does not issue Agent Baseline certification, claim official Docker conformance, prove completeness of telemetry that was never emitted, or infer causality merely because two assessment states differ. A causal before/after claim requires a controlled experiment with comparable inputs and environment.
