# Agent Baseline Evidence Lab v0.10.2

v0.10.2 is the final presentation-readiness patch for the v0.10 line. It keeps the assessment and Controlled Experiment semantics unchanged while ensuring that the downloadable release and the repository front door describe the **same reviewed state**.

## What changed since v0.10.1

- **Documentation integrity gate** — CI now fails when a relative Markdown link points to a missing file or escapes the repository root.
- **Controlled Experiment guide normalized** — the guide now uses the repository-wide core-document naming convention: `docs/CONTROLLED_EXPERIMENT.md`.
- **Architecture brought to the current implementation** — documents the three distinct planes: execution/assessment, assurance/handoff, and before/after experiment analysis.
- **Complete Claims Boundary** — explicitly separates product presence from enforcement, internal consistency from external trust, signatures from signer identity, recorded evidence from source completeness, local credential removal from provider revocation, and before/after change from causality.
- **Expanded Evidence Model** — formalizes declared, observed, linked and externally anchored evidence and connects them to integrity, authenticity, completeness, response evidence and before/after analysis.
- **Navigation cleanup** — removes the legacy interview-specific documentation path and keeps the public documentation customer/reviewer-neutral.

## Claims boundary

This remains a community implementation and assurance lab. A green CI, valid signature, verified evidence pack or `ELIGIBLE` Controlled Experiment result does not establish official Docker/Agent Baseline conformance, signer identity, source completeness or causality beyond the explicitly measured evidence boundary.
