# v0.13.1 — Self-contained customer policy distribution

v0.13.1 is a packaging and release-integrity patch for the v0.13 Customer Acceptance Envelope.

## Fixed

The example customer policy profiles are now included as Python package data instead of existing
only as repository-root files. A reviewer installing the wheel can therefore use the policy feature
without cloning the source repository.

Built-in profile references:

- `builtin:poc-observe`
- `builtin:enterprise-strict`

They can be discovered or exported with:

```bash
abl-policy list-profiles
abl-policy export-profile enterprise-strict --output customer-policy.yaml
```

Both `abl-policy evaluate` and `abl-accept create` accept `builtin:<name>` directly.

## Release verification

The clean-environment wheel smoke test now verifies:

- `abl-policy` is installed;
- `abl-accept` is installed;
- both built-in profiles are discoverable from the installed wheel;
- `enterprise-strict` can be exported from package data and contains the expected profile identity.

This closes the gap between source-tree functionality and downloadable-release functionality.

## Customer Acceptance Envelope

The v0.13 envelope semantics remain unchanged: the generic Customer Trust Handoff stays
policy-neutral, while the customer-specific envelope binds the verified handoff to an exact policy,
recomputed PASS evaluation, signed acceptance statement and signed final package.

## Claims boundary

The built-in profiles are examples only. They are not Docker recommendations, production
authorization criteria, compliance standards or certification requirements.
